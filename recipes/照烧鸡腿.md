# 照烧鸡腿

🥄第9道菜——🍲 照烧鸡腿
英国超市一磅的鸡腿，每次遇到必拿
🥬🥩食材：鸡腿
🧄🌶️佐料：蒜末 白芝麻
📜📌做法：
准备：
鸡腿 切块 蒜末 盐 黑胡椒 料酒 腌制15分钟
一勺生抽，一勺老抽，一勺蚝油，一勺蜂蜜
1. 鸡腿肉下锅煎至两面金黄
2. 倒入调好的料汁
3. 倒入水淀粉
4. 出锅撒白芝麻
