# 🍳 Chef Li's Recipes

## 📖 关于这本菜谱

除了是程序员，我还是一个厨子，这是我的个人菜谱合集（口味可能偏咸和辣口），记录日常做过的菜。每篇菜谱保留食材、佐料、制作步骤和原始图片，方便以后复刻，也方便分享给同样喜欢做饭的人。

点击下面任意首图或菜名，即可打开对应的完整菜谱。每篇文章中的第一张图片就是这个菜的成品，后续图片按照做菜或者准备的顺序排列。

> 🥢 菜谱仍在持续整理。如果你发现原始记录中有错字、用量不清或步骤遗漏，可以通过 GitHub Issue 提醒我。
